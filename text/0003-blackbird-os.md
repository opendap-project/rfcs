# RFC 0003: Rename OpenDAP OS to Blackbird OS

- **Status:** Accepted (2026-10-23).
- **Date:** 2026-10-23
- **Affected repositories:** every repository that names the operating system: blackbird-os (formerly opendap-os), workspace, blackbird-ui (formerly ui-components), toolkit-cli, claude-plugins, system, t1, board, hat-standard, hat-camera, hat-nas, hat-oscilloscope, hat-powerbank, hat-radio, hat-recorder, hat-vna (the HATs), faceplate-touch, faceplate-classic, faceplate-cassette (the faceplates), parts-lib, toolkit-host, toolkit-hardware, toolkit-verify, .github

## Summary

The operating system is renamed **Blackbird OS**. "Blackbird" stops being a release codename and becomes the product's name; releases are identified by their version number only. The repository `opendap-project/opendap-os` becomes `opendap-project/blackbird-os`.

## Motivation

"OpenDAP OS" repeated the umbrella brand and said nothing of its own; "Blackbird" was already public as the first release's codename ([opendap-os ADR 0009](https://github.com/opendap-project/blackbird-os/blob/main/docs/adr/0009-release-codenames.md)). Giving the system one stable name, independent of the release, makes it easier to refer to across documents, the device and the toolkit.

## Proposal

- **Name.** "Blackbird OS" everywhere "OpenDAP OS" was used, in prose, code comments, user-facing strings and brand assets. The brand architecture becomes: OpenDAP T1 · Blackbird OS · OpenDAP HATs · OpenDAP Developer Toolkit.
- **Versions.** Releases are named "Blackbird OS" plus a version number (OS-011 is unchanged). There are no release codenames: ADR 0009 and ADR 0010 are superseded by blackbird-os ADR 0011; `VERSION_CODENAME` is not set in `/etc/os-release`.
- **Repository.** `opendap-project/opendap-os` is renamed `opendap-project/blackbird-os` (GitHub redirects the old URL). The workspace folder becomes `public/blackbird-os`, and `repos.tsv` follows.
- **Identifiers.** Build identifiers follow the repository: the mkosi image ID, outputs and hostname, the Lima build VM (`blackbird-os-build`), the toolkit's workspace discovery (`public/blackbird-os`, `BLACKBIRD_OS_DIR`) and its `doctor` check (`workspace.blackbird_os`).
- **Brand assets.** The release lockups in `ui-components/brand/releases/blackbird/` are replaced by product lockups for Blackbird OS in `ui-components/brand/products/blackbird-os/`, generated by `logo.py`.
- **Unchanged.** Requirement IDs keep their `OS-` prefix. Crate names (`opendap-*`) and the `opendap` CLI keep their names: they belong to the OpenDAP Developer Toolkit, not to the OS.

## Alternatives

- **"OpenDAP Blackbird OS".** Keeps the umbrella brand in front, like OpenDAP T1. Not chosen: the maintainers want the system's own name to stand alone.
- **Keep codenames per release under the new name.** Not chosen: with the product named Blackbird, a second naming scheme per release adds no information.
- **Rename only the text, keep the repository name.** Not chosen: the maintainers prefer the repository to carry the product's name.

## Open questions

- A Blackbird OS visual identity beyond the generated lockups (its own mark, if any).
