# RFCs

Proposals for changes that span more than one OpenDAP repository, or that change an interface others build against.

Part of [OpenDAP](https://github.com/opendap-project). This repository is open source.

## Working here

- Write everything in English.
- Record only what the maintainers proposed or confirmed. Do not invent motivation, alternatives or decisions.
- Follow the process in `README.md`; start from `0000-template.md`. The maintainers decides acceptance.
- When an RFC is accepted, record the outcome in each affected repository with `/opendap:requirement` and, for decisions, `/opendap:adr`.
